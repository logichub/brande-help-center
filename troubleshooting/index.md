## How to Use This Guide

Each troubleshooting document follows this structure:

1. **Error Title** — The exact error message or issue
2. **Direct Answer** — The root cause in one sentence
3. **How to Fix This** — Step-by-step solutions (numbered)
4. **If This Doesn't Work** — Escalation steps and support contact

## Support Resources

- **Documentation** — Full feature docs available in Account Settings
- **Status page** — Check platform status at status.brande.ai

## Common Issues by Category

### API and Generation (Most Common)
- Brand DNA is incomplete or too vague
- Request exceeds size/complexity limits
- Temporary server load during peak hours
- Network timeouts

### Authentication and Access
- Email/password validation errors
- Password reset emails in spam folder
- Token expiration after 90 days
- Account locked after failed attempts

### File Handling
- Files exceed 25MB size limit
- Unsupported file formats (only PDF, DOCX, TXT, CSV)
- Uploads complete but analysis doesn't start
- Permission issues prevent deletion

### Subscription and Features
- Plan doesn't include requested feature
- Trial period has restrictions
- Collaborator slots are full
- API credits exhausted

## Getting Help

If you've tried all troubleshooting steps:

1. **Gather information**
   - Error message (exact text)
   - What you were trying to do
   - When it started happening
   - Any recent account changes

2. **Contact support**
   - Email: support@brande.ai
   - Include error message and steps you've tried
   - Attach screenshot if helpful
