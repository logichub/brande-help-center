# Content Agent Not Working

## Returns "Error Loading Recommendations"

**Direct Answer:** The Content Agent can't fetch recommendations due to incomplete Brand DNA or server issues.

### How to Fix This

1. **Complete your Brand DNA**
   - Go to Brand Settings
   - Fill in all required fields: Brand Voice, Tone, Core Values
   - Add audience information
   - Incomplete Brand DNA prevents recommendations from generating

2. **Verify the agent is enabled**
   - Go to Account Settings > Features
   - Confirm "Content Agent" is enabled
   - If disabled, contact support to enable it for your plan

3. **Check your subscription**
   - Content Agent requires Pro plan or higher
   - Verify your current plan includes this feature
   - Trial accounts have limited recommendations (3 per week)

4. **Refresh the page**
   - Reload the browser to clear stale data
   - Sometimes temporary server issues resolve on refresh

### If This Doesn't Work

- **Clear browser cache** — Settings > Privacy > Clear Browsing Data
- **Try a different browser** — Safari, Firefox, Edge
- **Wait and retry** — Server load during peak hours (9am-5pm) can cause slowness
- **Contact support** — Provide your Brand DNA details so we can debug

## Shows "No Recommendations Available for Today"

**Direct Answer:** The agent has already generated its daily limit of recommendations, or your Brand DNA is missing important context.

### How to Fix This

1. **Check the date**
   - Recommendations reset at midnight in your timezone
   - You might have hit today's limit; check back tomorrow

2. **Enhance your Brand DNA**
   - Add target audience information
   - Include industry/niche details
   - Add brand voice examples with tone
   - Richer Brand DNA produces better recommendations

3. **Verify your plan quota**
   - Trial: 3 recommendations per week
   - Pro: 10 recommendations per day
   - Team/Agency: Unlimited
   - If you've hit your limit, upgrade or wait until reset

4. **Manually create content instead**
   - Use the Generate Content feature directly
   - You're not limited by the agent's quota
   - Create your own prompts for unlimited generation

### If This Doesn't Work

- **Contact support** — We can reset your daily quota if needed
- **Check the time** — Recommendation reset happens at midnight; not instantly at noon

## Recommendations Appear But Say "Something Went Wrong"

**Direct Answer:** A recommendation failed to generate fully. Individual failures don't indicate a system error; try generating the recommendation manually.

### How to Fix This

1. **Click the failed recommendation**
   - Some recommendations generate correctly even if they show an error badge
   - Open it to see if content is actually there

2. **Generate content manually**
   - Copy the recommendation's topic/title
   - Go to Create Content and generate it directly
   - You'll have full control over length and tone

3. **Review the recommendation topic**
   - If the topic is too vague, the agent couldn't generate it
   - Edit your Brand DNA to be more specific
   - Retry tomorrow with updated guidelines

4. **Check your API quota**
   - Some plans have generation limits
   - Verify you haven't exceeded your monthly credits
   - Upgrade to add more quota

### If This Doesn't Work

- **Try again later** — Temporary server issues can cause individual failures
- **Submit the recommendation topic** — If a specific topic always fails, contact support
- **Disable and re-enable the agent** — Go to Settings > Features and toggle off/on

---

## Agent Is Disabled or Grayed Out

**Direct Answer:** Your plan doesn't include the Content Agent, or the feature hasn't been enabled for your account.

### How to Fix This

1. **Check your plan type**
   - Go to Account Settings > Subscription
   - Content Agent is included in Pro, Team, and Agency plans
   - Trial and Starter plans don't have access

2. **Upgrade to a plan that includes it**
   - Pro plan: Includes Content Agent
   - Cost: Check Billing page for current pricing
   - Upgrade takes effect immediately

3. **Contact support if you should have access**
   - Enterprise or special accounts may need manual enablement
   - Support can verify your plan and enable the feature

4. **Enable the feature in your account**
   - Go to Account Settings > Features
   - If Content Agent is listed but disabled, enable it there
   - Refresh after enabling
