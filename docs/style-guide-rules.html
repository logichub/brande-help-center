1 Feature Overview

What it is

A per-brand settings page where brand managers configure writing rules that Brande.ai must follow in all AI-generated content — tone, vocabulary, sentence structure, formatting, and more.

Where it lives

Account settings → Style Guide Rules tab. Rules are scoped to the selected brand and persist in brands.settings.styleRules in Directus.

Why it matters

Without this, AI output follows only the brand voice profile. Style rules add enforceable mechanical constraints — e.g. no rhetorical questions, spell out numbers under 10, em dashes only.

5 Data Model

TypeScript interface (frontend + backend shared)
interface StyleRulesSettings { // Style & Voice activeVoice: boolean; // default: false narrativePerson?: 'first' | 'second' | 'third' | null; maxSentenceLength?: boolean; maxSentenceLengthWords?: number; // default: 25 // ... 7 more style booleans // Sentence Structure & Rhetoric avoidContrastiveClauses?: boolean; // ... 7 more rhetoric booleans // Word & Phrase Rules bannedWords?: string[]; wordReplacements?: { from: string; to: string }[]; approvedTerminology?: string[]; // Tone & Register formalityLevel?: 'casual' | 'balanced' | 'formal' | null; humor?: 'none' | 'subtle' | 'contextual' | null; urgencyLevel?: 'low' | 'medium' | 'high' | null; readingLevel?: 'grade8' | 'general' | 'professional' | null; // Numbers & Data spellOutNumbersEnabled?: boolean; spellOutNumbersUnder?: number; // default: 10 percentageFormat?: 'symbol' | 'word' | null; largeNumberFormat?: 'commas' | 'k' | 'words' | null; // Punctuation & Formatting oxfordCommas: boolean; oxfordCommasMode: 'use' | 'omit'; dashPreference?: 'em' | 'en' | 'avoid' | null; ellipsisUsage?: 'allowed' | 'avoid' | 'dialogue-only' | null; bulletPointThreshold?: boolean; bulletPointThresholdCount?: number; // default: 3 // Spelling & Region region: string; // 'en-US' | 'en-GB' regionEnabled?: boolean; }
Persistence location in Directus
// brands collection → settings field (JSON) { "styleRules": { "activeVoice": true, "narrativePerson": "second", "formalityLevel": "balanced", "bannedWords": ["synergy", "leverage"], "wordReplacements": [ { "from": "utilize", "to": "use" } ], "dashPreference": "em", // ... other rules } }
Key reactivity notes
⚠️
Deep clone required: Arrays (bannedWords, approvedTerminology, wordReplacements) must be deep-cloned when copying to/from savedRules, otherwise push/splice mutations affect both refs and isDirty stays false. Uses JSON.parse(JSON.stringify(...)).
ℹ️
Oxford commas: Stored as two fields (oxfordCommas: boolean + oxfordCommasMode: 'use'|'omit') for backward compat. Exposed as two mutually exclusive checkboxes via Vue computed setters.

6 Prompt Output Example

ℹ️
The helper formatStyleRulesForPrompt() in intellecto-services/.../helpers/style-rules.ts converts saved rules into a bullet list injected at the top of every content generation prompt via the ${styleRules} template variable.
// Example output for a brand with these rules configured:STYLE GUIDE RULES (must be followed throughout the content):- Use active voice; avoid passive constructions. - Write in second person throughout. - Keep sentences to a maximum of 25 words. - Remove filler intensifiers (just, really, very, quite, actually, basically). - Avoid contrastive clauses using: but, however, although, though, while, yet, whereas, nevertheless. - Prefer declarative statements: subject + active verb + specific outcome. One idea per sentence. - Never use any of the following words or phrases: synergy, leverage, game-changing. - Apply these word substitutions: utilize → use, implementation → implementation. - Maintain a balanced tone throughout. - Target a professional reading level. - Spell out numbers below 10; use numerals for 10 and above. - Format percentages as 42%. - Use em dashes (—) for sentence breaks. - Standardize spelling and vocabulary to English (US).
