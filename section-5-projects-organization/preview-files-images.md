# Preview Files and Images Inside Brande.ai

View images and files directly in the editor without downloading. Brande.ai displays images inline as you work, so you see your full content layout in real-time.

## View images in the editor

When your project contains images:

- Images display inline in the editor as content blocks
- See exactly how text and images flow together
- Preview your content as it will appear when published
- No download needed

Click any image to view it full-size or edit its properties.
